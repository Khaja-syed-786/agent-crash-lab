What this prototype establishes

The fixed fixture tests a known marker and an explicit fallback summary. The exact-marker-v1 gateway checks only the raw marker; Base64 passes through. The optional raw-base64-fixture-v1 policy also checks its known Base64 representation. The separate evaluator recognizes the raw marker and its known Base64 form, not arbitrary encodings or paraphrases. This does not prove arbitrary agents are safe. Scripted mode never invokes a model. Opt-in local-model mode records actual behavior, including refusals and failures. History is held in memory and clears when the server stops; export evidence to retain it.
